# Vícejazyčnost UI · v59 (OPS-02)

Čeština je výchozí a zdrojový jazyk. Angličtina (`en`) a ukrajinština (`uk`) jsou volitelné jazyky
**žákovského rozhraní** – pro žáky s jiným mateřským jazykem. Učitelský cockpit je vždy česky.

## Co se překládá a co ne

| Překládá se | Nepřekládá se (zůstává česky / beze změny) |
|---|---|
| Žákovské UI: navigace, nadpisy stránek a sekcí, tlačítka, popisky formulářů, nápovědy k ovládání, prázdné stavy, chybové a flash hlášky, potvrzovací dialogy, `aria-label`, `title`, `placeholder`, `alt`, texty v JS (toasty, stavy, dialogy), e-maily žákům | **Výukový obsah**: texty lekcí, zadání a příběhy úrovní Labu, stránky manuálu příkazů, kvízové otázky a odpovědi, obsah materiálů – kontejner dostane `edu_content_lang_attr()` (při en/uk `lang="cs"`, WCAG 3.1.2) |
| Veřejné stránky: přihlášení, aktivace, reset hesla, soukromí, připojení k hodině | **Výstup simulovaného Linuxu** (zůstává anglicky jako ve skutečném systému) |
| Offline stránka labu (jen UI) | Učitelský cockpit (`teacher.php`, učitelské záložky, projektor) |
| | Identifikátory, názvy polí formulářů, hodnoty `value`/`data-*` použité v logice, CSS třídy, URL, klíče polí, `error_log`, výstup CLI nástrojů |

## API

```php
tr('Uložit')                                   // text (surový) – do HTML vždy e(tr(...))
tr('Ahoj, {jmeno}!', ['jmeno' => $name])       // parametry {jmeno}; hodnoty se escapují spolu s textem v e()
trn(['one' => '{n} bod', 'few' => '{n} body', 'other' => '{n} bodů'], $n)   // plurál, msgid = tvar 'other'
tr_html('Vyhrál tým {tym}!', ['tym' => '<strong>' . e($team) . '</strong>']) // věta s HTML – parametry MUSÍ být už escapované, výsledek NEobalovat e()
trm('Materiály')                               // jen označí literál pro extrakci (popisek v poli) – vykreslit přes e(tr($label))
edu_content_lang_attr()                        // ' lang="cs"' při en/uk, jinak '' – na kontejner výukového obsahu
edu_cs($lesson['title'])                       // český obsah uvnitř přeloženého UI → <span lang="cs">…</span> (en/uk), v češtině = e(); vrací HTML
edu_weekday_short(1..7)                        // zkratka dne z vlastní tabulky (ne katalog – „Po“/„Ne“ kolidují s „po“/„ne“)
```

```php
edu_content_note_html()                        // '<p class="edu-content-note" role="note">…</p>' při en/uk, jinak ''
edu_date($ts, 'date'|'date_short'|'datetime'|'time'|'weekday'|'day_month')  // bez ext-intl; cs „26. 9. 2026“, en „26 Sep 2026“, uk „26.09.2026“
edu_month($mesic, $jazyk = null)                // 2. pád cs („září“), plný název en/uk
edu_weekday($ts, $jazyk = null)                 // název dne v týdnu
edu_number($cislo, $desetin = 0)                // cs/uk desetinná čárka, en tečka
edu_lang_switcher_html($csrf, $returnUrl)       // formulář POST edu_set_lang; jen jazyky z edu_active_locales(); uk = "(beta)"
edu_active_locales()                            // ['cs', …] podle env EDUCANET_UI_LOCALES (výchozí "cs,en,uk"), cs vždy aktivní
edu_clear_locale()                              // smaže cookie jazyka (volat při odhlášení žáka – sdílené počítače)
```

JS (soubor musí běžet po `assets/i18n-v58.js`, který načítá `_layout.php`):

```js
var T = window.EduI18n;                                  // vždy s pojistkou: T ? T.tr('…') : '…'
T.tr('Uloženo.');  T.tr('Zbývá {n} s', {n: 5});
T.trn({one: '{n} bod', few: '{n} body', other: '{n} bodů'}, n);
T.locale;                    // kód jazyka z <html lang> (ne z JSON dat)
T.contentLang(el);           // jazyk nejbližšího předka s [lang] (pro logiku uvnitř edu_content_lang_attr() obalu)
T.date(timestampMs, opts);   // Intl.DateTimeFormat(cs-CZ|en-GB|uk-UA)
T.number(cislo, opts);       // Intl.NumberFormat(cs-CZ|en-GB|uk-UA)
```

## Jazykový kontext, JSON bloky, manifest, audit

- Cookie `edu_lang` platí jen na žákovských vstupních skriptech (`index.php`, `progress.php`,
  `lab_v57_api.php`, `robots_v58_api.php`, `teamgames_v58_api.php`, `arena_v58_events_api.php`
  – `EDU_LOCALE_COOKIE_SCRIPTS` v `i18n_v58.php`). Jinde (`teacher.php`, exporty, CLI audity) je
  vždy čeština bez ohledu na cookie. `$GLOBALS['edu_locale_override']` má vždy přednost.
- `EDUCANET_UI_LOCALES` (env, výchozí `cs,en,uk`) omezuje, které jazyky jsou nabízené v přepínači
  a přijímané cookie; čeština je vždy aktivní. Škola tak může dočasně skrýt rozpracovaný jazyk.
- `edu_tr_json($domains)` vkládá jednu doménu nejvýš jednou za request jako
  `<script type="application/json" class="edu-tr-json" data-edu-tr="doména">{msgid: překlad, …}</script>`
  (pro češtinu nic). `assets/i18n-v58.js` líně slučuje všechny bloky `.edu-tr-json` (i starší
  jednoduchý blok `#edu-tr`) při prvním `EduI18n.tr()`/`trn()`. Jazyk se čte z `<html lang>`,
  nikdy z JSON dat; při inicializaci se zrcadlí do `localStorage.edu_lang` (try/catch) pro
  offline stránku labu.
- `lang/domains_v59.php` je manifest soubor → doména (PHP `domains`, JS `js`) podle
  `scratchpad/v59/PLAN_I18N.md` „Rozdělení“; čte ho `tools/v59_i18n_audit.php`.
- Audit: `C:/php/php.exe tools/v59_i18n_audit.php` (vše), `--core` (jen jádro), `--domain=<d>`
  (extrakce/pokrytí jen pro jednu doménu), `--no-http` (bez HTTP sekce), `--strict-domains=a,b`
  (HTTP sekce FAILuje na `<html lang>`/přepínači/diakritice i pro vyjmenované, jinak jen hlásí
  `INFO` počty – převod ještě neběží). Builder po dokončení domény spustí
  `tools/v59_i18n_audit.php --domain=<svoje doména> --no-http` (musí PASS) a při integraci
  `--strict-domains=<svoje doména>`.

## Katalogy

- `lang/en/ui/<domena>.php` a `lang/uk/ui/<domena>.php`, JS řetězce v `lang/<jazyk>/ui/js_<domena>.php`
  (vkládá je `edu_tr_json_js()` v hlavičce stránky). **Čeština katalog nemá** – zdrojem je kód.
- Formát (každý soubor): `<?php` + `declare(strict_types=1);` + guard proti přímému přístupu + `return [...]`.
  ```php
  return [
      'Uložit' => 'Save',
      '{n} bodů' => ['one' => '{n} point', 'other' => '{n} points'],           // en: one, other
  ];
  // uk plurály: ['one' => …, 'few' => …, 'many' => …]
  ```
- Klíč = **přesně** český text ze zdroje (včetně interpunkce, pevných mezer a typografických znaků).
- Každá doména patří jednomu vlastníkovi (jeden agent / vývojář) – žádný sdílený katalog.
- Chybí-li překlad, zobrazí se čeština (nikdy surový klíč). Pokrytí hlídá `tools/v59_i18n_audit.php`.

## Pravidla převodu

1. **Čeština se nesmí změnit** – vykreslené HTML v češtině je po převodu bajtově stejné (kromě úmyslných změn).
2. Skládané věty převést na jednu větu s `{param}` (slovosled se v jiných jazycích liší); čísla → `trn()`.
3. Text s HTML uvnitř → `tr_html()` s už escapovanými parametry, nikdy `tr()` bez `e()`.
4. Popisky v polích (navigace, karty, stavy) → `trm('…')` v definici, `e(tr($label))` při výpisu. Pole,
   jejichž hodnoty kontroluje logika nebo audit, se nemění – překládá se jen při výpisu.
5. Výjimky, které se ukazují žákovi: `throw new RuntimeException(tr('…'))`. Flash hlášky se ukládají už přeložené.
6. Obsah (lekce, úroveň, otázka, stránka manuálu) nepřekládat; element, který ho obaluje, dostane `edu_content_lang_attr()`.
7. Nic, co je v rozporu s `e()`/`safe_url()` a CSRF – převod nesmí oslabit escapování.
