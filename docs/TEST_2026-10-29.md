## Prostředí a ochrana dat

Playwright 1.63.0 z `~/Projects/prezentace/node_modules/playwright`, systémový Chromium, PHP 8.5.11 přes `/usr/bin/php`.
Server běžel na `http://127.0.0.1:8090` s `PHP_INI_SCAN_DIR=:$HOME/.config/php/conf.d`.
Každý běh kopíruje celou aplikaci do vlastní složky `/tmp/quiet-study-*`; `EDUCANET_STORAGE_DIR` ukazuje na kopii `storage/`.
`EDUCANET_TEACHER_EXPORT_KEY` vzniká pomocí `crypto.randomBytes(32)` pouze v paměti, předává se prostředím serveru a po ukončení procesu zaniká. Není v souborech ani výstupech.
Testovací student vstupuje přes existující vývojový vstup (`EDUCANET_DEV_BYPASS=1`), učitel přes skutečný přihlašovací formulář s dočasným klíčem.
Otevřená hodina je založena pouze v kopii dat pomocí existujícího `sess53_open()` pro 3.A, lekci 7 a dnešní datum.
SHA-256 obsahu a cest skutečných `storage/`, `private/`, `uploads/` se porovnává před a po běhu. Nevznikly nové závislosti.

Použité skilly: ponytail, context-management, frontend-design, testing, webapp-testing a codebase-memory.
`design:accessibility-review` není instalovaný; použity dostupné pokyny `testing/references/accessibility.md` a projektové audity.
Graf byl vytvořen bez persistence; neparsovatelné PHP šablony a vyloučené CSS/JS byly ověřeny přímo ve zdroji.

## Rozsah

Každá stránka na 1440 a 390 CSS px, světlá a tmavá preference systému, omezený pohyb.
Starší stránky, které tmavý motiv nepodporují, podle stávající konfigurace zůstávají světlé.

| Oblast | Testovaná adresa / stav |
|---|---|
| Domů | `/?view=dashboard`, jeden aktuální krok; oba stupně progresu |
| Učit se | `/?view=materialy`, navíc starší `course` → Materiály / Lekce |
| Moje cesta | `/?view=pokrok`, navíc starší `knowledgebase` → Materiály / Témata |
| Třída | `/?view=community` |
| Lekce dnes – žák | `/?view=hodina` bez otevřené hodiny (správně přesměruje do materiálů) i s otevřenou testovací hodinou |
| Lekce dnes – učitel | `/teacher.php?tab=hodina&class=class_3a` |
| Příprava hodiny | `/teacher.php?tab=priprava79&class=class_3a`, klikáním kroky 1 → 2 → 3 → 4 |
| Kalendář | studentský `calendar` i učitelský `tab=calendar`; výběr měsíců klávesnicí |
| Cockpit | `/teacher.php?tab=attention` |

Před opravou 40 základních měření + 4 měření otevřené hodiny. Po opravě navíc 8 měření starších adres: celkem 52.
Sondy sbírají konzoli, `pageerror`, HTTP odpovědi ≥ 400, PHP Warning/Notice/Fatal/Deprecated/Parse/Uncaught,
vodorovný posun dokumentu, písmo pod 14 px, cíle pod 44 × 44 px a kontrast viditelného textu.
Výpočet kontrastu vychází ze skutečných vypočtených barev, skládá průhledná pozadí a respektuje limit 3:1 pro velký text / 4,5:1 pro ostatní.
Jde o vzorek maximálně 600 textových prvků na měření; gradienty a obrázková pozadí výpočet vynechává.

## Reprodukce

```bash
rtk proxy node tools/visual_qa_2026_10_29.cjs after
```

Příkaz spustí vlastní PHP server na 8090, náhodný klíč ponechá v paměti, provede test a server ukončí.
Adresář musí být spuštěn z kořene repozitáře a port 8090 musí být volný. Výsledky uloží do `docs/screens-2026-10-29/after-results.json`, snímky do stejné složky a PHP log do dočasné složky uvedené v JSON.
`before` změří původních 40 variant; `before-active` měří jen 4 varianty otevřené hodiny; `after-active` je cílený regresní test stejného stavu. Volitelný třetí argument je cesta k úplné výchozí kopii aplikace.
