# Lesson Presentation Mode

Lesson Mode je určený pro projektor / velkou obrazovku během 2 × 45 minut.

## Použití

1. Otevři `Teacher → Výuka`.
2. U konkrétní lekce zvol `▶ Spustit hodinu`.
3. Volitelně zapni `Celá obrazovka`.
4. Tlačítkem `Spustit hodinu` začne 90minutový timer.

Aktuální etapa se na časové ose zvýrazňuje automaticky. Timer lze pozastavit nebo resetovat; změna časovače nijak nemění studentská data.

## Doporučený princip

Lesson Mode není teleprompter. Má učiteli a studentům ukázat pouze:

- cíl,
- právě probíhající fázi,
- očekávaný výstup,
- co dělat, když první vysvětlení nestačí.

Detailní teacher notes zůstávají v pravém panelu.
