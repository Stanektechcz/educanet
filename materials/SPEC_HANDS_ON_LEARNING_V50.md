# Specification · EDUCANET v50 Hands-on Learning

## Learning loop

`hypothesis → command/evidence → state validation → explain → transfer → stop-rule`

The terminal is formative evidence, not a command-count score. Validation is based on target state rather than one exact repair path.

## Coverage

- 3.A SOSaPS: 28/28 Hands-on labs.
- 4.A SOSaPS: 28/28 Hands-on labs.
- 18 problem families.
- Skill Passport dimensions: principle, recognition, diagnosis, repair, explain, transfer.
- Peer roles: Driver, Observer, Explainer with structured notes.

## Independent Growth

12 voluntary paths branch from learned fundamentals into webdesign/frontend/PHP/backend and other extensions. Unlocking reads existing school evidence plus separate Growth Progress. Growth completion never writes required curriculum grading/XP/Mastery.

## Runtime contract

Default: deterministic stateful simulator. Optional: localhost-only rootless OCI broker with bearer auth, fixed profiles/images, independent command allowlist, no host mounts, `--network none`, dropped capabilities by default, bounded resources/time and automatic session cleanup.
