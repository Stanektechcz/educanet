## Doporučený učitelský rytmus

1. **Před lekcí:** ověř cíl, evidence, Knowledge materiály, student output a diferenciaci.
2. **Během lekce:** krátký model → práce studenta → iterace → QA/validace → exit ticket.
3. **Před projektem:** brief, role, Definition of Done, QA gate, peer feedback a retrospektiva.
4. **Při hodnocení:** odděluj týmový výsledek od individuální role; Mastery vzniká jen z ověřené evidence.
5. **Po projektu:** publikuj konkrétní feedback, nech proběhnout retrospektivu a projdi Skill heatmap.

## Třídy

### 1.A · Grafika a webdesign · základy

Od vizuálních základů k prvnímu responzivnímu webovému návrhu.

- **1–4 · Vizuální základy:** Hierarchie, kompozice, typografie, obraz a první vizuální identita.
- **5–9 · Systém a produkce:** Konzistence, redesign, více formátů, layout, produkční workflow.
- **10–14 · Webové základy:** Anatomie webu, responsive, komponenty, webová typografie a obraz.
- **15–18 · Přístupný web + capstone:** Formuláře, accessibility, wireframe, UI kit a responzivní landing page.
- **19–23 · Vysvětlení, obsah a responsive praxe:** Visual audit, content-first layout, responsive hero, microcopy a přístupná typografie.
- **24–28 · Art direction + týmová aplikace:** Image art direction, komponentové states, critique, landing sprint a portfolio/mastery.

**Capstone:** Responsive Landing Sprint  
**Mastery:** Design 40 % · Typography 30 % · UI/UX 30 %

### 2.A · Grafika a webdesign

Od vizuálního systému k UI/UX, testování, handoffu a produktové case study.

- **1–4 · Vizuální systém + digitální formáty:** Kampaň, hero sekce, motion storyboard a adaptace designu.
- **5–9 · Design systém + interakce:** Tokeny, komponenty, portfolio case study, accessibility a profesionální handoff.
- **10–14 · UX architektura + implementovatelnost:** IA, user flow, Form UX, Auto Layout, accessibility audit a HTML/CSS handoff.
- **15–18 · Responsive implementace + ověřování:** Flex/Grid mindset, usability testing, Design QA a produktový capstone.
- **19–23 · Research + robustní UX:** Research framing, card sorting, component stress test, error recovery a accessible interaction.
- **24–28 · Handoff + evidence:** Design tokens, usability round 2, Design QA, product sprint a case study/mastery.

**Capstone:** Product Page Studio  
**Mastery:** Design 40 % · Typography 30 % · UI/UX 30 %

### 3.A · Seminář operačních systémů a počítačových sítí

Od síťové diagnostiky k Linux administraci a kombinovanému incidentu.

- **1–4 · Síťové služby + diagnostika:** TCP/IP, VLAN, DNS/DHCP, monitoring, firewall a evidence-first troubleshooting.
- **5–9 · Adresace + packet/service debugging:** IPv6, DNS záznamy, reservations, Wireshark mindset, VLSM a service debugging.
- **10–14 · Linux administrace:** CLI/filesystem, users/groups/permissions, procesy, systemd, logy a SSH/SFTP.
- **15–18 · Služby + automatizace + incident:** Firewall/listeners, Linux web service, shell/cron a kombinovaný Linux + network incident.
- **19–23 · Linux troubleshooting do hloubky:** Filesystem incident, systemd dependencies, journal forensics, SSH klíče a DNS evidence chain.
- **24–28 · Firewall + automatizace + mastery:** Stateful firewall, bezpečný Bash, service recovery, team incident a mastery review.

**Capstone:** Linux + Network Incident Lab  
**Mastery:** Networking 40 % · Linux 35 % · Security 25 %

### 4.A · Seminář operačních systémů a počítačových sítí

Produkční správa, bezpečné změny, recovery, observability a reliability.

- **1–4 · Production change + observability:** Change window, proxy/TLS, logy, metriky, health, release a rollback.
- **5–9 · Reliability engineering:** HTTP observability, canary, backup/restore, SLO/error budget, IaC/drift a capacity.
- **10–14 · Linux production operations:** systemd dependencies, storage, RPO/RTO, hardening a containers.
- **15–18 · Automatizace + incident response:** Idempotentní automatizace, packet/socket evidence, runbook, postmortem a reliability drill.
- **19–23 · Observability + recovery:** Golden signals, reverse proxy evidence, container networking, restore game day a hardening audit.
- **24–28 · Safe change + incident leadership:** Rollback, drift automation, performance/capacity, incident command a reliability mastery.

**Capstone:** Production Reliability Drill  
**Mastery:** Networking 35 % · Linux 35 % · Security 30 %
