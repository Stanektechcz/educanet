# Visual Labs v43 · přehled podle ročníku

## 1.A · DGD / Grafika + webdesign
Laboratoře používají především design canvas, map renderer a responsive manipulaci. Pokrývají hierarchii, typografii, barvu/kontrast, image crop, identitu, responsive layout, komponenty, formuláře, accessibility, content-first layout, critique a portfolio.

## 2.A · GRA / pokročilá grafika + UI/UX
Laboratoře pokrývají branding systém, responsive adaptaci, motion, design tokens, UI komponenty, informační architekturu, form recovery, auto layout, accessibility audit, handoff do HTML/CSS, usability testing, QA a case study.

## 3.A · SOSaPS
Laboratoře používají flow/timeline renderer. Pokrývají IP/DNS/DHCP, routing, VLAN/subnet, packet journey, monitoring, Linux filesystem, permissions, systemd, journal, SSH, firewall, web service, Bash/cron a kombinované incidenty.

## 4.A · SOSaPS / reliability
Laboratoře pokrývají routing/CIDR, reverse proxy/TLS, observability, load balancing, release/rollback, backup/restore, SLO, IaC/drift, capacity, advanced systemd/storage, hardening, containers, packet diagnostics a incident command.

Každá lekce má samostatný `.md` soubor v `materials/cognitive_labs/<class>/lesson_XX.md`.
