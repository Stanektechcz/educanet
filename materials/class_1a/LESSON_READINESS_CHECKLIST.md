# 1.A · Lesson readiness checklist

Použij před každou hodinou. Interaktivní verze je v **Teacher Cockpit → Výuka**.

## 01 · Lekce 1 · Základní dvouhodinový blok

**Cíl:** 2 × 45 minut: rychlá vstupní diagnostika → vizuální knowledge tour → návrhový sandbox → převod do Canvy → kontrola a mini-prezentace. Nejde o známku; cílem je bezpečně pochopit základní principy.

- [ ] Cíl a success/evidence criteria jsou jasné.
- [ ] Knowledge / zdroje jsou dostupné.
- [ ] Praktický studentský výstup je připravený.
- [ ] Je připravená podpora / nápověda bez prozrazení řešení.
- [ ] Je připravené rozšíření pro rychlejší studenty.
- [ ] Exit ticket / validace pochopení je připravená.

**Poznámky z balíčku:**
- Startovací vizuální laboratoř pro první ročník: co je hierarchie, kontrast, grid, typografie a jak z jednoduché konfigurace převést návrh do Canvy.
