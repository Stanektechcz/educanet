# 1.A · Teacher checklist

**Předmět:** Grafika a webdesign · základy  
**Mastery:** Design 40 % · Typography 30 % · UI/UX 30 %  
**Capstone:** Responsive Landing Sprint

## Před začátkem období

- [ ] Projít COURSE_MAP a ověřit pořadí 28 strukturovaných lekcí + 12 aplikovaných střed.
- [ ] Ověřit přihlášení studentů, třídu a studentské profily.
- [ ] Ověřit dostupnost Teacher Guide, Workbooku, Assessment Bank a Project Briefs.
- [ ] Zkontrolovat Skill Mastery váhy a hlavní větve pro třídu.
- [ ] Vybrat, které individuální a týmové projekty budou skutečně hodnocené.

## Před každou lekcí

- [ ] Mít jasný cíl lekce a evidence, podle které poznám splnění.
- [ ] Ověřit Knowledge Tour / zdroje a případnou simulaci.
- [ ] Připravit konkrétní studentský výstup, ne pouze výklad.
- [ ] Připravit podporu pro studenty, kteří potřebují menší rozsah nebo nápovědu.
- [ ] Připravit smysluplné rozšíření pro rychlejší studenty.
- [ ] Mít exit ticket / krátkou validaci pochopení.

## Před týmovým projektem

- [ ] Publikovat brief, success criteria a povinné výstupy.
- [ ] Nastavit role Leader / Designer / Researcher / Developer / Presenter / QA podle projektu.
- [ ] Zvolit způsob tvorby týmů a doporučenou velikost skupiny.
- [ ] Definovat Definition of Done a QA gate před finálním odevzdáním.
- [ ] Naplánovat self reflection, peer feedback a týmovou retrospektivu.

## Hodnocení a Mastery

- [ ] Zkontrolovat rubriku před zadáním, ne až při hodnocení.
- [ ] Hodnotit konkrétní evidence a rozhodnutí, ne množství kliknutí.
- [ ] U týmové práce vyhodnotit individuální roli každého studenta.
- [ ] Publikovat pouze ověřenou Skill Evidence relevantní k projektu.
- [ ] Studentovi publikovat silnou stránku a jeden konkrétní další krok.

## Uzavření období

- [ ] Zkontrolovat, že byly probrány všechny povinné tematické bloky.
- [ ] Projít class Skill heatmap a identifikovat společné mezery.
- [ ] Dát studentům možnost vybrat ověřené projekty do profilu/portfolia.
- [ ] Zapsat, co v kurzu zachovat, změnit a vyzkoušet příště.

## Specificky pro 1.A

- [ ] Připrav Canva/Figma prostředí a ověř přístup studentů.
- [ ] Připrav legální obrazové zdroje nebo vlastní fotografie pro cvičení.
- [ ] U accessibility lekcí připrav grayscale/focus/contrast kontrolu.
- [ ] Před capstone připrav brief a success criteria pro landing page.
