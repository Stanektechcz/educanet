# 2.A · Projektové briefy

## Product Page Studio
Tým navrhne, otestuje a předá produktovou landing page.

**Doporučené role:** Leader/Designer/Researcher/Developer/Presenter/QA

**Povinné výstupy:**
- IA + user flow
- responsive prototype
- component/state spec
- usability evidence
- accessibility audit
- handoff + case study

**Týmová pravidla:**
- Každý student má jednu primární roli.
- Task je hotový až po Definition of Done.
- Critical QA nález musí být ověřen před finálním odevzdáním.
- Peer feedback není automatická známka.
- Po projektu proběhne self reflection + team retrospective.
