# 2.A · Studentský pracovní sešit

Předmět: **Grafika a webdesign · UI/UX**

> Vyplňuj stručně. Důležitější je konkrétní důkaz a zdůvodnění než dlouhý text.

## Lekce 10 · Informační architektura + user flow

**Cíl:** Navrhnout strukturu malého webu podle úkolů uživatele a převést ji do jednoznačného user flow.

### Můj pracovní list
- [ ] Content inventory.
- [ ] Sitemap.
- [ ] 1 user flow.
- [ ] 3 testovací úkoly.
- [ ] 1 iterace podle pozorování.

### Reflexe
- Co jsem změnil/a po testu nebo feedbacku?
- Jaký konkrétní důkaz mě k tomu vedl?
- Co bych příště udělal/a dřív nebo jinak?
