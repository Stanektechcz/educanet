# 3.A · Projektové briefy

## Linux + Network Incident Lab
Tým obnoví testovací službu při kombinované síťové a OS závadě.

**Doporučené role:** Leader/Researcher/Developer/Presenter/QA

**Povinné výstupy:**
- incident timeline
- network evidence
- service/log evidence
- minimální oprava
- validation matrix
- retrospektiva

**Týmová pravidla:**
- Každý student má jednu primární roli.
- Task je hotový až po Definition of Done.
- Critical QA nález musí být ověřen před finálním odevzdáním.
- Peer feedback není automatická známka.
- Po projektu proběhne self reflection + team retrospective.
