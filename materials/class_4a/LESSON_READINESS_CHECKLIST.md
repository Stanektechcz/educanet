# 4.A · Lesson readiness checklist

Použij před každou hodinou. Interaktivní verze je v **Teacher Cockpit → Výuka**.

## 01 · Lekce 1 · Základní dvouhodinový blok

**Cíl:** Kompletní blok na 2 × 45 minut: startovní test → cílený rozbor → realistická case study s topologií a simulovaným terminálem → praktické incidenty s nápovědami a kontrolou → exit ticket. Kdo dokončí celý blok dřív, odemkne dobrovolný Extra challenge na známku.

- [ ] Cíl a success/evidence criteria jsou jasné.
- [ ] Knowledge / zdroje jsou dostupné.
- [ ] Praktický studentský výstup je připravený.
- [ ] Je připravená podpora / nápověda bez prozrazení řešení.
- [ ] Je připravené rozšíření pro rychlejší studenty.
- [ ] Exit ticket / validace pochopení je připravená.

**Poznámky z balíčku:**
- Pokročilejší diagnostika zaměřená na síťové scénáře, služby, SSH a troubleshooting. Není na známku.
