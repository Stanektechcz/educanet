# 4.A · Projektové briefy

## Production Reliability Drill
Tým stabilizuje simulovaný produkční incident a připraví postmortem.

**Doporučené role:** Leader/Researcher/Developer/Presenter/QA; Designer volitelně pro dashboard

**Povinné výstupy:**
- severity + role assignment
- evidence matrix
- mitigation/rollback
- recovery validation
- preventive automation proposal
- postmortem

**Týmová pravidla:**
- Každý student má jednu primární roli.
- Task je hotový až po Definition of Done.
- Critical QA nález musí být ověřen před finálním odevzdáním.
- Peer feedback není automatická známka.
- Po projektu proběhne self reflection + team retrospective.
