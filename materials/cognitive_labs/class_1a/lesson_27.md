## Situace
Text je vizuálně efektní, ale při skutečném čtení se ztrácí rytmus a hierarchie. V této lekci je cílem: V týmu vytvořit funkční responzivní landing page od briefu po QA.

## Freeze & predict
Co máš upravit dřív než font efekty?
- A. Velikost, řádkování, délku řádku a hierarchii **← očekávaný směr**
- B. Přidat stín
- C. Použít více fontů

## X-Ray vrstvy
- **Obsah** — Co text sděluje.
- **Typografická hierarchie** — Nadpis, perex, body a pomocné texty.
- **Rytmus** — Line-height, mezery a délka řádku.
- **Font** — Volba řezu až v rámci funkčního systému.

## Timeline scrubber
1. Urči role textu
2. Nastav hierarchii
3. Zkontroluj délku řádku
4. Vylaď line-height
5. Ověř reálný obsah

## Cause → Effect controls
- Řádkování: 12–40px; start 18px; functional target 26px
- Nadpis: 18–72px; start 34px; functional target 48px
- Délka řádku: 280–900px; start 820px; functional target 560px

## Contrast case
**Typická past:** Dlouhý řádek, malý rozdíl nadpis/body a stísněný rytmus.

**Funkční model:** Čitelná délka řádku, stabilní rytmus a jednoznačná hierarchie.

**Proč:** Typografie řídí čtení; font je pouze jedna část systému.

## Build the model
`Obsah → Role textu → Hierarchie → Rytmus → Font`

## Reverse engineering
Vidíš pouze chybný výsledek. Která předchozí vrstva nebo rozhodnutí ho mohlo způsobit?
- Obsah: Co text sděluje.
- Typografická hierarchie: Nadpis, perex, body a pomocné texty.
- Rytmus: Line-height, mezery a délka řádku.

## Transfer
Použij stejný princip na jiný formát, obsah nebo viewport, který v ukázce nebyl.
